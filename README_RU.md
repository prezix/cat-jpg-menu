# Cat-JPG-Menu

Кастомное меню для Garry's Mod с cat.jpg-стилистикой, оформлением интерфейса, загрузочным экраном и коллекцией из более чем 30 обоев.

[English version](README.md)

## О проекте

Cat-JPG-Menu - настраиваемый аддон меню для Garry's Mod.

Первоначально проект был разработан **twenty two** и **babzoid1**. Этот репозиторий сохраняет оригинальную кодовую базу проекта и продолжает её поддержку для современных версий Garry's Mod.

Текущая разработка сосредоточена на:

* Исправлении ошибок
* Обновлении совместимости
* Повышении производительности
* Добавлении новых возможностей
* Долгосрочной поддержке проекта

## Первоначальные разработчики

* **twenty two**
* **babzoid1**

## Возможности

* Кастомное главное меню Garry's Mod
* Набор фонов в стиле cat.jpg
* Более 30 встроенных обоев
* Собственный загрузочный экран
* Оформление меню, списка серверов и страницы новой игры
* Включённые материалы и UI-ассеты

## Установка

1. Скачайте последний релиз или клонируйте репозиторий.
2. Поместите папку проекта в директорию `addons` вашего Garry's Mod.
3. Запустите Garry's Mod.

Пример пути:

```text
steamapps/common/GarrysMod/garrysmod/addons/Cat-JPG-Menu
```
