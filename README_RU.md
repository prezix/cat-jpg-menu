# Cat-JPG-Menu

Кастомное меню для Garry's Mod с cat.jpg-стилистикой, оформлением интерфейса, загрузочным экраном и коллекцией из более чем 30 обоев.

[English version](README.md)

## О проекте

Cat-JPG-Menu - настраиваемый аддон меню для Garry's Mod.

Первоначально проект был разработан **twenty two** и **babzoid1**. Этот репозиторий сохраняет оригинальную кодовую базу проекта и продолжает её поддержку для современных версий Garry's Mod.

## Возможности

* Кастомное главное меню Garry's Mod
* Набор фонов в стиле cat.jpg
* Более 30 встроенных обоев
* Собственный загрузочный экран
* Оформление меню, списка серверов и страницы новой игры
* Включённые материалы и UI-ассеты
* Анимации: переходы между страницами, поочерёдное появление пунктов меню, hover-эффекты, всплывающие окна, экран загрузки
* Кнопка «Следующие обои» в нижней панели
* Окно настроек (кнопка с лапкой): цвет акцента (6 вариантов), вкл/выкл анимаций, праздничные эффекты, коты во всех режимах. Сохраняется в `garrysmod/data/catjpg_menu.txt`
* Снег зимой и падающие листья на Хэллоуин
* Коты во всех режимах, у которых нет своих обоев
* Экран загрузки: случайный кот на фоне, статус, полоса прогресса скачивания, текущий файл, сменяющиеся советы (русский / английский)
* Интерфейс на русском и английском
* Цветокоррекция: виньетка и тонировка в цвет акцента поверх обоев, сила настраивается (0-100%)
* Полная тёмная тема для всех страниц: главная, новая игра, серверы, аддоны, дупы, сейвы, демо, диалоги, поля поиска
* Индикаторы загрузки в цвете акцента: спиннер на страницах Workshop, полоса сверху при обновлении списка серверов
* Анимации котов: парящий и покачивающийся логотип, слайдшоу котов с наездом камеры и плавной сменой на экране загрузки
* Экран загрузки берёт цвет акцента и цветокор из настроек главного меню
* Учитывается системная настройка «уменьшить движение»

## Установка

1. Скачайте последний релиз или клонируйте репозиторий.
2. Поместите папку проекта в директорию `garrysmod` вашего Garry's Mod.
3. Запустите Garry's Mod.

Пример пути:

```text
steamapps/common/GarrysMod/garrysmod/
```

## Обновление со старой версии

Старые версии содержали полные копии стандартных файлов меню (`Menu.css`, `NavBar.css`, шаблоны, `loading.css` и т.д.) и обои в PNG. Текущая версия только добавляет свои файлы поверх стандартных, поэтому обновления Garry's Mod больше не ломают меню.

1. Удалите старые `*.png` из `garrysmod/gamemodes/sandbox/backgrounds/` (обои теперь в `.jpg`, в 6 раз легче).
2. В Steam: Garry's Mod → Свойства → Установленные файлы → **Проверить целостность файлов игры**, чтобы вернуть стандартные файлы меню.
3. Снова скопируйте новую версию в `garrysmod`.

> После обновления Garry's Mod Steam может вернуть стандартные `html/menu.html` и `html/loading.html`. Если тема пропала — просто скопируйте аддон ещё раз.

## Как это устроено

| Файл | Назначение |
| --- | --- |
| `html/menu.html` | Стандартная страница меню + `catjpg.css`, `catjpg.js` и кнопка смены обоев |
| `html/css/menu/catjpg.css` | Цвета темы и анимации, грузится после стандартных стилей |
| `html/js/menu/catjpg.js` | Оборачивает стандартный `MenuController`: окно настроек, цвета, праздничные эффекты, кнопка обоев; через Lua патчит `pnlMainMenu:UpdateBackgroundImages()`, чтобы коты были во всех режимах |
| `html/loading.html` | Стандартный экран загрузки + `catjpg-loading.css` и `js/catjpg-loading.js` |
| `html/js/catjpg-loading.js` | Случайный кот, статус, прогресс, текущий файл, советы (оборачивает стандартные `GameDetails`, `SetFilesTotal`, `SetFilesNeeded`, `DownloadingFile`, `SetStatusChanged`) |
| `html/catjpg-loading.css` | Тема и анимации экрана загрузки |
| `gamemodes/sandbox/backgrounds/*.jpg` | Обои главного меню (их подхватывает `lua/menu/mainmenu.lua`) |
