# GMOD Menu

A customizable menu addon for Garry's Mod.

## About

This project was originally developed by **twenty two** and **babzoid1**.

The repository is now actively maintained by the current maintainer. Development focuses on fixing bugs, improving compatibility with modern Garry's Mod versions, optimizing performance, and introducing new features.

## Original Developers

* twenty two
* babzoid1

## Current Maintenance

* Bug fixes
* Performance improvements
* Compatibility updates
* New features
* Long-term support

## Installation

1. Download or clone this repository.
2. Place it into your Garry's Mod `addons` directory.
3. Launch the game.
